# Document-Masking-AI-Powered-Insights-System
AI-powered system for detecting and masking PII in documents using NER, Regex, OCR, OpenCV, and ONNX, with a FastAPI backend and React frontend

## Features

- PII detection using NER and Regex
- Face and ID-card masking
- OCR-based text extraction
- FastAPI backend
- React frontend
- OpenCV-based image processing

## Technologies

- Python
- FastAPI
- React
- OpenCV
- NER
- Regex
- OCR
- ONNX
